# Backup Retention SOP

Status: active
Date: 2026-06-27

Operational backups are retained for 90 days. Audit logs are retained for 400
days. Retrieval traces containing customer content are retained for 45 days unless
a legal hold requires longer storage.

This SOP covers backups only. It does not set the knowledge-base document
retention rule, which is defined in the multilingual data-retention notice.
