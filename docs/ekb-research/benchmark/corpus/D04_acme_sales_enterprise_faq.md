# Enterprise Buyer FAQ

Status: active
Date: 2026-06-27

Q: Can a buyer ask for answers with no citations?
A: No. Beacon Answers requires citations unless the response is a no-answer.

Q: Can support agents query HR policy documents?
A: Only if the workspace grant explicitly includes that document or group.

Q: What is the default answer when the system cannot find permitted sources?
A: The answer must say that no permitted source supports the claim.

Q: Are retrieval scores visible?
A: The API exposes document_id, chunk_id, score, index_version, and trace_id.
