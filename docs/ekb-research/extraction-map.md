The comparison matrix contains the required `donor_eligible` pre-filter. No
framework with `security_gate=FAIL` is recommended because no dossier currently
has that gate. More importantly, no source-filter-only retrieval ACL result is
recommended as a donor for authorization or retrieval policy. Those subsystems
are assigned to OpenFGA, OPA, and first-party pipeline logic.
