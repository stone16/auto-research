## Q1 - SEO/GEO Architecture

Build SEO/GEO as UI -> domain adapter/tools -> AI recommendation -> content store/publisher -> evaluator, with identity, credentials, schedules, ledgers, approvals, and kill-switches in shared Core. `getuai-seo` supplies the UI/MCP/AI split (`runs/growth-engine-from-scratch/sources/_raw/getuai-seo.md:7-11`, `:93-97`); `getuai-plugin` supplies crawler/search/competitor/keyword tool inputs (`runs/growth-engine-from-scratch/sources/_raw/getuai-plugin.md:11-20`, `:117-126`); ranking comes from `getuai-seo` metrics and LLMRush GEO rank/sentiment (`runs/growth-engine-from-scratch/sources/_raw/getuai-seo.md:101-106`; `runs/growth-engine-from-scratch/sources/_raw/LLMRush.md:7-14`); content storage/publishing comes from `rankncompare` JSON/static SEO surfaces (`runs/growth-engine-from-scratch/sources/_raw/rankncompare.md:28`, `:53-56`, `:128-149`). Disagreement: product-shell vs static-publisher vs Core-owned platform facts (`runs/growth-engine-from-scratch/sources/_raw/growth-engine-legacy.md:43-50`). Recommendation: Core approval, override, action ledger, and kill-switch before publishing or recurring checks (`runs/growth-engine-from-scratch/sources/_raw/growth-engine-legacy.md:83-88`).

## Q2 - Content Writing Architecture

Content is a staged pipeline: ideation from campaign/entity facts, outline through prompt templates, draft through LLM generation, edit/review by humans or rules, publish/send through SMTP/web/channel output, and post-publish through response/rank/attribution measurement. `getuai-email-2.0` provides Campaign CRUD, Recipients import, SMTP test, Batch create, AI generate, review, and send (`runs/growth-engine-from-scratch/sources/_raw/getuai-email-2.0.md:70-73`, `:91-118`). Load-bearing choices are prompt-variable injection, recipient schema, mandatory SMTP test, human review, and session/artifact storage (`runs/growth-engine-from-scratch/sources/_raw/getuai-email-2.0.md:14`, `:91-99`, `:111-118`; `runs/growth-engine-from-scratch/sources/_raw/getuai-api.md:24-40`). Stylistic choices are UI shape and template format. OpenClaw adds reusable generation/summarization/transcription primitives for non-email channels (`runs/growth-engine-from-scratch/sources/_raw/openclaw-marketing.md:153`, `:5104-5152`, `:6656-6716`).

## Q3 - Ads Architecture

Ads is campaign feed -> bidding/budget/targeting -> reporting -> attribution -> optimization. `getuai-ads` has the UI/MCP/AI shell and external Google Ads/DeepSeek dependencies (`runs/growth-engine-from-scratch/sources/_raw/getuai-ads.md:7-11`, `:24-28`, `:66-100`). `getu_ads_v2` is the platform-bound mutation/query shell with stdin/file JSON, `ResultEnvelope`, failure envelopes, and 38 operations (`runs/growth-engine-from-scratch/sources/_raw/getu_ads_v2.md:9-67`, `:1010-1017`). `getuai-ads-data` is the platform-agnostic reporting lake for campaigns, conversions, and cross-platform sources (`runs/growth-engine-from-scratch/sources/_raw/getuai-ads-data.md:7`, `:15`, `:159-164`, `:216-250`). Attribution is SDK -> ingress/consumer -> Pub/Sub/event tables -> dashboard (`runs/growth-engine-from-scratch/sources/_raw/attribution_v2.md:13-16`). Platform SDKs and mutations are isolated; ResultEnvelope, event schema, reporting lake, anomaly/pacing rules, and kill-vs-scale gates are shared. Human-in-loop is the read/write split in `lawyer_marketing` (`runs/growth-engine-from-scratch/sources/_raw/lawyer_marketing.md:248-269`).

## Q4 - Social Architecture

Social decomposes into listen, post, schedule, engage, and monitor. Listen is strongest in `reddit-scount`, which analyzes URL/company context, extracts keywords/pain points/competitors/subreddits, discovers posts, and fetches comments (`runs/growth-engine-from-scratch/sources/_raw/reddit-scount.md:108-121`, `:124-181`). YouTube is a search adapter (`runs/growth-engine-from-scratch/sources/_raw/youtube-api-demo.md:7-20`, `:48-54`). X post/reply/search exists through OpenClaw `xurl` (`runs/growth-engine-from-scratch/sources/_raw/openclaw-marketing.md:7392-7422`, `:7502-7507`). OpenClaw Gateway is the closest multi-platform abstraction: control plane, inbox, routing, sessions, tools, cron/webhooks, and per-channel adapters (`runs/growth-engine-from-scratch/sources/_raw/openclaw-marketing.md:132-158`). Quota/credit accounting comes from `x-api-credit-monitor` (`runs/growth-engine-from-scratch/sources/_raw/x-api-credit-monitor.md:7-17`, `:72-104`). Moderation belongs after generation and before public action, using DM pairing/allowlist gates (`runs/growth-engine-from-scratch/sources/_raw/openclaw-marketing.md:122-126`).
